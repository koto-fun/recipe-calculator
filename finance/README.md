# Фінансовий трекер (локальний)

Односторінковий застосунок для обліку інвестиційних портфелів, бюджету та фінансового планування. Інтерфейс українською, валюта — USD.

## Запуск

Жодної установки не потрібно — просто відкрийте `finance/index.html` у будь-якому сучасному браузері (подвійний клік по файлу). Працює повністю офлайн.

За бажання можна запустити через локальний сервер (доступ лише з вашого комп'ютера):

```bash
cd finance
python3 -m http.server 8000 --bind 127.0.0.1
# відкрийте http://127.0.0.1:8000
```

## Приватність

- Усі дані зберігаються у `localStorage` вашого браузера — жодних серверів і акаунтів.
- Застосунок не виходить у мережу, доки ви не додасте API-ключ для котирувань.
- Резервні копії: «Налаштування → Експорт JSON» (та Імпорт для відновлення).

## Розділи

- **Дашборд** — вартість усіх портфелів, зміна за день/всього, пасивний дохід, готівка з подушкою безпеки, графік капіталу по місяцях.
- **Портфелі** — створення портфелів, активи з P/L, ручне або автоматичне оновлення цін, дивіденди на акцію.
- **Угоди** — журнал угод/доходів/витрат/переказів із фільтрами (портфель, тикер, дати), пагінацією та режимом Dense.
- **Бюджет** — рахунки, статистика балансу за 6 місяців, річні плани з прогресом, діаграма витрат за категоріями.
- **Планер** — складний відсоток із вибором валюти (€/$/₴); режими «Шаблон портфеля» (ризик-профіль задає дохідність) або «Дохідність вручну»; інфляція, зростання поповнень, податок; оцінка ризику й просадки. Графік прогнозу з трьома сценаріями (оптимістичний/реалістичний/песимістичний), перемикач типу графіка (área/лінія/стовпці), номінальна/реальна вартість і підказки при наведенні. Режим «Розрахувати пенсію» додає фазу виплат (роки пенсії, щомісячні витрати, дохідність на пенсії) з окремим графіком накопичення та витрачання.

## Котирування ринку (необов'язково)

Без ключа ціни активів задаються вручну (клік по ціні в таблиці активів). Для автоматичного оновлення:

1. Зареєструйтеся на [finnhub.io](https://finnhub.io) і отримайте безкоштовний API-ключ.
2. Вставте його в «Налаштування → Котирування ринку».
3. Натискайте «⟳ Оновити ціни» на сторінці портфеля.

Ключ зберігається тільки у вашому браузері.
